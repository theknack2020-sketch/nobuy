## 2. Keyword Optimization

### Current Issues
- 4 duplicated words across fields → ~20 chars wasted
- "no spend" in keywords but also "no" + "spend" in title
- "impulse" in both subtitle and keywords
- "buy" variant in both subtitle ("Buying") and keywords

### Optimized Strategy

**APP NAME** (unchanged — ranking established):
```
NoBuy: No Spend Day Tracker
```
(29/30 chars) — "NoBuy", "No", "Spend", "Day", "Tracker" all indexed

```
Mindful Money · Save Smarter
```
